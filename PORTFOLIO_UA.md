# Інтеграція: вебхуки → Google Sheets на FastAPI (демо-проєкт)

**Демо-проєкт для портфоліо.** Зроблений для демонстрації навичок, не на замовлення клієнта. Дані в прикладах тестові.

**Задача.** Автоматично збирати замовлення з сайту або заявки з форм у Google-таблицю, щоб менеджер бачив їх одразу, без ручного копіювання. Ні підроблені запити, ні повторні доставки не повинні псувати таблицю, а короткий збій Google не має губити замовлення.

**Рішення.**
- FastAPI-сервіс з endpoint для вебхуків та автоматичною документацією OpenAPI (Swagger).
- Перевірка HMAC-SHA256 підпису і часу запиту: чужий або перехоплений запит відхиляється.
- Ідемпотентність: кожна подія записується рівно один раз, дублікати від платіжки чи CRM ігноруються.
- Повтори запису з наростаючою затримкою; якщо таблиця недоступна, сервіс просить відправника повторити, і подія не губиться.
- Змінний «writer»: справжній Google Sheets через service account або локальний CSV для тестів і демо.
- Docker / docker-compose для розгортання на VPS, налаштування через .env.

**Стек.** Python 3, FastAPI, Pydantic v2, gspread, SQLite, Docker, pytest.

**Результат.** Робочий сервіс з 11 автотестами на підпис, повтори, дублікати й валідацію. Демо-прогін: 3 події прийнято й записано, дублікат проігноровано, запит з підробленим підписом відхилено (401). Той самий підхід підходить для WayForPay / LiqPay / Monobank, Tilda, WooCommerce, KeyCRM тощо, з адаптацією під формат їхнього підпису.
